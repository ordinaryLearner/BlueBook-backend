## 目标

给用户(User)添加一个「收藏」(favorites) 属性，存储该用户收藏的帖子(Post)列表，并新增增/删收藏帖的 API。

注意：本项目是 **Node.js + Express + PostgreSQL（原生 pg / JSONB）**，不是 Java/Spring。所谓"给 user 加一个 post 列表属性"将实现为：在 `users` 表新增一个 JSONB 数组列 `favorites`（存帖子 id），完全复用现有 `followers`/`fans`/`likes` 的存储与读取风格。

## 存储层改动

### `src/config/database.js`
仿照现有幂等迁移，加入收藏列的建表/清理：
1. 在 `initDatabase()` 中，对 `users` 表补一条幂等 `ALTER TABLE users ADD COLUMN IF NOT EXISTS favorites JSONB DEFAULT '[]'::jsonb`（紧跟现有 followers/fans 迁移附近，逻辑一致）。
2. 调用现有的 `cleanNonArrayColumns('users','favorites')` 脏数据清理，保证历史遗留非数组值被重置为 `[]`。

### `src/models/user.js`
展开对外返回字段并富化：
1. `PUBLIC_COLUMNS` 加入 `favorites`（放在 `fans` 之后），这样注册/查询/更新用户返回都会带出该字段。
2. `enrichProfile()` 中保证 `user.favorites` 一定是数组：`user.favorites = Array.isArray(user.favorites) ? user.favorites : [];`（结果仍是帖子 id 列表，不内嵌完整 post，避免 self-reference 膨胀）。

## 收藏操作数据方法

在 `src/models/post.js`（帖子域数据层）新增函数，结构完全对齐现有 `addLike/removeLike` 与 `findLikedPostsByUserId`：

- `addFavorite(userId, postId)`：把 postId 加入 `users.favorites`，用 `@> $2::jsonb` 去重 + `||` 追加，更新 `updated_at`，返回该用户的 favorites 数组。
- `removeFavorite(userId, postId)`：用 `jsonb_array_elements` + `jsonb_agg` 把 postId 从 `favorites` 移除，返回新 favorites。
- `isFavorited(userId, postId)`：判断 postId 是否在 favorites 内（对齐 `user.js` 的 `isFollowing`）。
- `findFavoritePostsByUserId(userId)`：仿照 `findLikedPostsByUserId`，用 `WHERE p.id = ANY(收藏id数组)`… 查询 `posts` 并 JOIN 用户生成 sender，`attachCommentsToPosts` 富化，按已收藏顺序/创建时间返回完整帖子列表。

新增函数在 `module.exports` 中导出。(一个取舍：id-to-posts 的批量解析也可直接写 `WHERE p.id = ANY($1::uuid[])` 一次查回，这里用独立查询函数，语义清晰。)

## 控制器层

### `src/controllers/postController.js`
在文件顶引入相应 model 函数后新增 handler，完全沿用本文件 getMyPosts/getMyLikedPosts 的写法，**当前登录用户一律用 `req.userId`（JWT），postId 来自路径参数**：

- `favorite`(收藏某帖)：
  1. `const postId = req.params.id; const userId = req.userId;`
  2. `findPostById(postId)` 不存在 → 404 `帖子不存在`。
  3. 已收藏(`isFavorited`) → 400 `已收藏该帖子`。
  4. `addFavorite` 后返回 `{ code:200, message:'收藏成功' }`。
- `unfavorite`(取消收藏)：
  1. 未收藏 → 400 `未收藏该帖子`。
  2. `removeFavorite` 后返回 `{ code:200, message:'取消收藏成功' }`。
- `getMyFavorites`(分页取收藏的完整帖子列表)：复用 `findFavoritePostsByUserId(req.userId)`，对齐 `getMyLikedPosts` 的返回结构；出错 500 `获取我收藏的帖子失败`。

（消息文案与现有风格保持中文。）

## 路由层

### `src/routes/postRoutes.js`
采用 follow/unfollow 的路径风格，添加带 `authenticate` 的路由：
- `router.post('/:id/favorite', authenticate, postController.favorite);` （收藏）
- `router.delete('/:id/favorite', authenticate, postController.unfavorite);` （取消收藏）
- `router.get('/myfavorites', authenticate, postController.getMyFavorites);` （我收藏的帖子列表）

注意：`/:id/favorite` 与现有 `router.get('/:id', ...)`、`/my`、`/myfavorites` 不冲突（Express 按注册顺序 + 具体路径段匹配，`myfavorites` 不受 `:id` 影响）。

## 不改动的地方
- 用户的收藏属性在 `findById`/资料接口返回的是收藏帖子 **id 数组**（`favorites`），与粉丝/关注字段一致；需要完整帖子时走 `GET /api/posts/myfavorites`。
