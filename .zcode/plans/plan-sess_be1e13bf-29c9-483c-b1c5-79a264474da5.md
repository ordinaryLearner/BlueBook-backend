## 火山引擎翻译代理接口（Node/Express）

已确认的关键点：
- 项目是 **Node.js + Express + pg**（非 Java/Spring），新功能按 `routes/controllers/utils` 分层加，用 `{code, message, data}` 返回约定。
- 接口**公开、无需鉴权**；请求体**只有 `text`**，目标语言固定 `zh`、源语言自动识别。
- **重要修正**：你给的 SecretAccessKey 是 **base64 二次编码**的。解码一次得 `Y2JiMjM2NzZlZTcyNGE5OGFmMzIxOWU2ZjUxZTE3MDM`，再解码才是真实 32 位 hex 密钥 `cbb23676ee724a98af3219e6f51e1703`。这是火山引擎控制台的常见形式，代码里会在运行时 base64 解码后再作为 HMAC 密钥使用（否则签名必然失败）。

### 1. 新增 `src/utils/volcTranslate.js`
把 Kotlin `VolcTranslateClient` 的 V4 签名逻辑逐行移植到 Node，用已存在但未使用的 `axios` 发请求，Node 内置 `crypto` 做 SHA256/HMAC。
- 常量：`HOST=open.volcengineapi.com`、`REGION=cn-north-1`、`SERVICE=translate`、`VERSION=2020-06-01`、`ACTION=TranslateText`。
- 密钥从 `process.env.VOLC_ACCESS_KEY` / `VOLC_SECRET_KEY` 读取；**SK 先用 `Buffer.from(sk,'base64')` 解码**，解析出的 hex 文本作为 HMAC key 的字节来源（与官方 SDK 行为一致）。
- `translate(text, target='zh', source='auto')`：
  - body `{ TargetLanguage, SourceLanguage, TextList:[text] }`
  - 时间戳 ISO8601 UTC `yyyyMMdd'T'HHmmss'Z'`，`dateStamp` 取前 8 位
  - canonicalRequest = POST / `/` / `Action=TranslateText&Version=2020-06-01` / 4 个规范化头（content-type、host、x-content-sha256、x-date）/ signedHeaders / body 的 SHA256
  - credentialScope `$dateStamp/$REGION/$SERVICE/request` → stringToSign → 签名密钥链 HMAC(`VOLC`+decodedSK → dateStamp → region → service → `request`) → 最终签名
  - axios POST，带 `Host`、`Content-Type`、`X-Date`、`X-Content-Sha256`、`Authorization`；用 `transformRequest` 保证发出的字节与参与哈希的 body 完全一致，`validateStatus` 避免非 2xx 抛异常
  - 解析 `TranslationList[0].Translation`，失败返回 `''`（与 Kotlin 行为一致）
- 辅助函数 `sha256Hex` / `hmac` / `hmacHex` / `signatureKey` / `decodeSecretKey`，`module.exports = { translate }`。

### 2. 新增 `src/controllers/translateController.js`
沿用现有控制器风格（async 导出、内联校验、try/catch、中文 `console.error`、`{code,message,data}`）：
- 校验 `text` 必须为非空字符串（trim 后），否则 `400 {code:400,message:'翻译内容不能为空'}`
- 长度上限 5000 字符 → `400 {code:400,message:'翻译内容长度不能超过5000个字符'}`（如需别的上限告诉我）
- 调用 `volcTranslate.translate(text)`；结果为空 → `500 {code:500,message:'翻译失败，请稍后重试'}`
- 成功 → `res.json({ code:200, message:'success', data:{ translation } })`

### 3. 新增 `src/routes/translateRoutes.js`
```js
const router = require('express').Router();
const translateController = require('../controllers/translateController');
router.post('/', translateController.translateText);
module.exports = router;
```
不加 `authenticate`。

### 4. 修改 `src/app.js`
`require('./routes/translateRoutes')` 并 `app.use('/api/translate', translateRoutes);`

**最终接口**：`POST /api/translate`，body `{"text":"Hello"}` → `{"code":200,"message":"success","data":{"translation":"你好"}}`
